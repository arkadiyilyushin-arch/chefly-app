# Chefly

Mobile social network for professional chefs, home cooks, and food lovers.

Share recipes, follow kitchen news, discuss on the forum, and message fellow cooks.

## Features

- **Home feed** — stories + recipe/video posts
- **Forum** — news and discussions by category
- **Messages** — chats with cooks and circles
- **Profile** — stats, bio, media grid
- **Create** — post recipes, photos, videos, or forum topics

## Run

```bash
npm start
```

Then press `i` for iOS simulator, `a` for Android, or scan the QR code with Expo Go.
